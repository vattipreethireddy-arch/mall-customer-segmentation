# mall-customer-segmentation
Mall Customer Segmentation using K-Means Clustering in Python to group customers based on annual income and spending score, with data visualization using Matplotlib and Seaborn.

Mall Customer Segmentation Using K-Means Clustering
Project Overview
This project uses Machine Learning to group mall customers based on their annual income and spending score using the K-Means Clustering algorithm.

Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- 
Algorithm
K-Means Clustering

Project Steps
1. Load the mall customers dataset.
2. Select annual income and spending score.
3. Scale the data using StandardScaler.
4. Use the Elbow Method to help choose the number of clusters.
5. Apply K-Means Clustering.
6. Visualize the customer groups.
7. Save the results to a CSV file.
8. 
Results
- Identified customer groups based on income and spending score.
- Visualized customer segments using scatter plots.
- Saved the cluster assignments in a CSV file.
Output
The project generates an Elbow Method graph and a Customer Segmentation graph.
